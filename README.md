# Tourify 🌴

Tourify is a modern, premium web application designed for a luxury Indian tourist agency. It features a stunning, fully responsive user interface built to showcase the breathtaking beauty of Incredible India. This project emphasizes a sleek design language, engaging micro-animations, and a highly polished user experience.

![Tourify Hero](public/images/hero.png)

## 🌟 Key Features

*   **Modern Premium Aesthetic:** Built using a custom glassmorphism design system inspired by top tier agencies, utilizing a vibrant color palette of Saffron, Ashoka Green, and Deep Navy.
*   **Dynamic Itinerary Galleries:** Detailed travel packages complete with rich image galleries, pricing in INR (₹), and day-wise itineraries in a beautiful pop-up modal.
*   **Fully Responsive:** Pixel-perfect fluid layout that transitions smoothly from desktop wide-screens to mobile devices, featuring a custom mobile hamburger menu.
*   **WhatsApp Integration:** Single-click "Connect with an Expert" and live floating chat buttons perfectly integrated to instantly route customers to the booking team.
*   **State of the Art Animations:** Subtle hover states, slow zoom hero imagery, and smooth fade-in transitions designed to captivate visitors.

- **React.js** (Bootstrapped via Vite for lightning-fast HMR)

- **HTML5** (Semantic structure & SEO)

## 🛠️ Installation & Setup

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd tourify
   ```

2. **Install NPM Packages:**
   ```bash
   npm install
   ```

3. **Start the Development Server:**
   ```bash
   npm run dev
   ```

4. **View in Browser:**
   Open [http://localhost:5173](http://localhost:5173) to view it in your browser.
